# DaveHarness 0.5.0 run state contract

H3 adds a serializable, host-neutral run state machine. `RunSnapshot` contains a run ID, status, optimistic version, transcript, counters, optional deadline, pending call, executed-call and decision ledgers, and an event cursor. `RUN_STATE_VERSION = 1` is independent of the H1 leaf envelope. Unknown versions, missing or extra fields, invalid status combinations, nonfinite JSON, and noncanonical string-backed JSON fail closed.

`transition_run` is the only status and version transition. A terminal status is immutable. `resume_run` and `decide_run` use a host-supplied `SnapshotCAS` protocol to reserve each model invocation and tool call before invoking an injected dependency. A reserved but unresolved operation is not replayed after an interruption. H6 will supply a bounded production store and lifecycle facade; H3's test store round-trips each snapshot through JSON.

An approval-required call pauses as `PendingToolCall` with canonical validated arguments, SHA-256 argument digest, tool-definition fingerprint, permission, registry registration revision, transcript revision, nonce, and expiry. `ApprovalDecision` must match its run, call, digest, fingerprint, permission, nonce, and time window. The decision ID is consumed through compare-and-swap before any effect. A changed definition, revocation, expired or mismatched decision, or duplicate attempt cannot execute. The new lifecycle has no name-level preapproval field; approval requires an exact pending decision. Calls remaining in the same model message survive the pause without repeating earlier calls or budget charges.

The current DaveLLM HTTP routes still use the shipped `run_executor_loop` and `resume_executor_loop` compatibility adapter. DaveHarness neither stores DaveLLM projects nor chooses roots, credentials, models, persistence, or transport. Existing endpoint fields, status strings, default-off tools, separate shell opt-in, authentication, containment, and redaction remain owned by their existing layers. H4 adds [cancellation and absolute deadline enforcement](DAVEHARNESS_H4_CANCELLATION.md); H5 adds events; H6 adds the production facade and store; H7 integrates DaveLLM.
